# ChatBridge

Espacio de intercambio de archivos entre Thiago y ChatGPT mediante GitHub.

## Carpetas

- `uploads/`: archivos que Thiago comparte para que ChatGPT los revise.
- `downloads/`: archivos preparados por ChatGPT para que Thiago los descargue.
- `images/`: capturas e imágenes de referencia.

## Cómo usarlo

1. Subí los archivos a la carpeta correspondiente desde GitHub.
2. Compartí en el chat el enlace del repositorio o del archivo.
3. Para recibir un archivo, revisá `downloads/`.

## Importante

- No subir contraseñas, tokens, claves API ni información privada.
- GitHub no es almacenamiento ilimitado: respetar sus límites de tamaño y uso.
- Los archivos binarios (imágenes, PDF, ZIP, etc.) se suben desde la interfaz web de GitHub o con Git; el conector puede leer y crear archivos de texto, pero no siempre puede adjuntar binarios directamente.
